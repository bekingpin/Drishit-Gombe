# Nimbu Mirchi Charm

A playful VS Code extension where the user picks **exactly one** of three charms:
- Demon Head
- Nimbu Mirchi
- Lady Charm

## Test it
```powershell
npm install
```
Then press **F5** in VS Code. Open the Nimbu Mirchi icon in the Activity Bar and choose one charm.

You can also use `Ctrl+Shift+P` → `Nimbu Mirchi Charm: Choose Charm`.

## Package it
```powershell
npx vsce package
```
